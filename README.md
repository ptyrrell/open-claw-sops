# Open Claw SOPs

Reusable playbooks generated by Alfred from real calls — Loom demos, Fathom sales calls, Zoom recordings, internal walkthroughs. Each SOP is a markdown file with YAML frontmatter; a Node build script renders the HTML site published to GitHub Pages.

**Live site:** [ptyrrell.github.io/open-claw-sops/](https://ptyrrell.github.io/open-claw-sops/)

## How to add a new SOP

### Option A — text Alfred (recommended)

> "Alfred, turn this loom into an SOP: https://www.loom.com/share/<id>"

> "Alfred, draft an SOP from my last Fathom call called *<title>*"

Alfred fetches the source, runs it through Claude with `prompts/sop-from-transcript.md`, commits a new file in `sops/`, pushes, and replies with the live URL once the GitHub Action build completes (~30s).

### Option B — by hand

1. Drop a new markdown file in `sops/<slug>.md` with this frontmatter:

   ```yaml
   ---
   title: "Plain-English title"
   slug: <kebab-case-slug>
   owner: Paul Tyrrell
   status: live          # live | draft | archived
   summary: "1-2 sentence card description"
   source:
     type: loom          # loom | fathom | zoom | grain | manual
     url: https://...
     label: "Display label"
   tags: [sales, demo]
   created: 2026-05-12
   updated: 2026-05-12
   related:
     - other-sop-slug
   ---
   ```

2. Body uses the section headings in [prompts/sop-from-transcript.md](prompts/sop-from-transcript.md) — When to use, Outcome, Prerequisites, Steps, Decision tree, FAQ, Definition of done, Related artefacts.

3. Run `npm run build` and commit. The GitHub Action also builds on push.

## Build locally

```bash
npm install
npm run build           # builds docs/ from sops/
open docs/index.html
```

## How it works

```
sops/<slug>.md  +  templates/sop.html  +  templates/_layout.html
        │                            │
        └────── scripts/build.mjs ───┘
                       │
                       ▼
        docs/sops/<slug>.html  +  docs/index.html
                       │
                       ▼
                GitHub Pages serves /docs
                       │
                       ▼
       https://ptyrrell.github.io/open-claw-sops/
```

## Where this fits in Open Claw

```
Loom / Fathom / Zoom / Grain  →  Alfred (cursor_spawn_agent or sop_from_loom tool)
                                    │
                                    ├── reads transcript / summary
                                    ├── runs prompts/sop-from-transcript.md through Claude
                                    ├── writes sops/<slug>.md
                                    └── commits + pushes  →  GitHub Action builds  →  Pages
```
